# Research Papers

This folder contains two research papers developed as part of my final-year major project, **Autonomous Mobile Robot with Gesture Recognition, Line Following and Obstacle Avoidance**, completed as part of my B.Tech in Mechatronics Engineering at Manipal Institute of Technology.

The papers explore vision-based hand gesture recognition, simulated robot control, and the implementation of an autonomous mobile robot using a Raspberry Pi and the Freenove 4WD platform.

## 📄 Paper 1: Vision-Based Gesture Recognition Using MediaPipe and MATLAB

**Title:** Vision-Based Gesture Recognition for Simulated Robot Control Using MediaPipe and MATLAB

**Overview:**

This paper explores a vision-based gesture recognition system using MediaPipe and OpenCV to identify hand gestures from landmark data. The recognized gestures are used to control a differential-drive robot in a MATLAB simulation.

**Key Areas:**
- Hand landmark detection using MediaPipe
- Gesture classification using hand landmark geometry
- OpenCV-based vision processing
- Differential-drive robot control in MATLAB
- Gesture recognition performance and response latency

**Technologies:** Python, MediaPipe, OpenCV, MATLAB

📎 **Paper:** [`gesture-recognition-mediapipe-matlab.pdf`](gesture-recognition-mediapipe-matlab.pdf)

## 🤖 Paper 2: Autonomous Mobile Robot Using Raspberry Pi and Freenove 4WD

**Title:** Autonomous Mobile Robot with Gesture Recognition and Obstacle Avoidance Using Raspberry Pi and Freenove 4WD Platform

**Overview:**

This paper presents the implementation of a mobile robot using a Raspberry Pi 4B and Freenove 4WD platform. The system integrates hand gesture recognition with obstacle detection to support interactive robot control and autonomous movement.

**Key Areas:**
- Gesture recognition using MediaPipe
- Raspberry Pi-based robot control
- Obstacle detection using an HC-SR04 ultrasonic sensor
- Integration of hardware and computer vision
- Evaluation of gesture recognition performance and command latency

**Technologies:** Raspberry Pi 4B, Python, MediaPipe, OpenCV, HC-SR04 Ultrasonic Sensor, Freenove 4WD

📎 **Paper:** [`gesture-controlled-mobile-robot.pdf`](gesture-controlled-mobile-robot.pdf)

## Relationship to the Major Project

Both papers are related to the same major project but focus on different aspects of the system: the first focuses on vision-based gesture recognition and simulated robot control, while the second focuses on the physical robot implementation and obstacle avoidance.
